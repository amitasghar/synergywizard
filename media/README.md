# Marketing media

Rebuild: `npm run short:record` (films the live site, writes `marketing/short/.work/`), then `npm run short:build`.
Use another soundtrack: `npm run short:build -- --music "path/to/track.mp3" [--music-start 12.5]`
(`--music-start` = seconds into the track where the music should begin; defaults live at the top of `marketing/short/build.mjs`).
The track is read in place and never copied into the repo.
